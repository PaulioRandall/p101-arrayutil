# Package: Elemental

Classes that provide a simplified way to apply changes to [JavaScript Elements](https://developer.mozilla.org/en-US/docs/Web/API/Element).

## Classes

**[Elemental](./Elemental.md)** provides a simplified way to apply changes to a specific element. When auto update is disabled, allows batching of changes to the element. Inherits _ElementConfig_.

**[ElementConfig](./ElementConfig.md)** Provides a simplified way to apply property configurations to elements.
