# P101: JavaScript Research & Development Sandbox

Paulio's personal JavaScript development sandbox. Create a new package for a new project. If it begins to look promising I move it to its own repo.

I also use this repo to test published packages function when imported. A decade of JavaScript programming and I still face issues with libraries that run fine when in the repo but fail when imported; tis a drawback of remote dependencies and interpreted languages.

## Made to be Plundered

Copy+paste packages, classes, and functions as needed from _[/src](./src)_. Tests are written in [Jest](https://jestjs.io/) but should be easy to adapt to whatever you use.
